### Concepts
*(recurring ideas, principles, tactics)*

- [[concept-data-commoditisation]] -- data is near-free; distribution and execution are the moat (Robinson).
- [[concept-lean-autonomous-gtm]] -- simple product + AI support + founder brand = near-autonomous at scale (Robinson).
- [[concept-waterfall-enrichment]] -- query providers in priority order until a field is filled (Clay, now in CLIs).
- [[concept-agentic-sourcing]] -- describe ICP in plain English; agent builds, enriches, scores the list.
- [[concept-claim-tagging]] -- tag claims [VERIFIED]/[INFERRED]/[ESTIMATED]/[UNAVAILABLE] (Waxman).
- [[concept-skill-namespacing]] -- Claude Code skills silently shadow across scopes; commit and prefix (Waxman).
- [[concept-agent-readiness]] -- how directly an agent can operate a tool, scored across its agent surfaces (Toizer).
- [[concept-borrow-from-engineering]] -- GTM is ~18 months behind software engineering; steal its agent patterns (Toizer).
- [[concept-deterministic-first]] -- make every paid API and AI call justify itself; free deterministic steps first (Nowoslawski).
- [[concept-list-is-the-message]] -- segment by who a company sells to; if a data point changes the message, split the campaign (Nowoslawski).
- [[concept-locked-cta]] -- lock the CTA and give all data points upfront so an optimising agent cannot win the wrong way (Nowoslawski).
- [[concept-context-assembly]] -- assemble and unify context upstream before the agent reads it; fix it at the data layer, not the prompt (Tittarelli).
- [[concept-aeo]] -- answer engine optimisation: structure pages so LLMs can parse and cite you (Tittarelli).
- [[concept-compounding-channel-stack]] -- network, referrals, owned audience, community; each layer carries the next (Tittarelli).
- [[concept-gtm-functions]] -- package GTM logic once as a callable function; call not copy, edit once, propagate everywhere (Clay).
- [[concept-signal-vs-intent]] -- intent is who might be interested; signal is who is moving and why, in a short window; stop hoarding (Jha).
- [[concept-orchestration-layer]] -- buy the systems of record, build the connective layer above them in weeks (Lynch).
- [[concept-ai-first-buyer-journey]] -- AI and peers shape preference before the search; presence must live upstream (Even).
- [[concept-data-vs-reasoning-layer]] -- Clay does breadth/accuracy (data), Claude does depth/judgment (reasoning); decouple and optimise each (Jha, Wolfe, Schaber).
- [[concept-silent-failures]] -- in agentic pipelines silent failure is the default; the winning tool builds the auditability layer (Wolfe).
- [[concept-foundations-before-automation]] -- AI multiplies whatever foundation exists; PMM hat + revops hat first or scale the noise (Moscatiello).
- [[concept-hybrid-gtm]] -- human+AI hybrid beats full automation, tested at Ramp; the empirical counterweight to the replacement hype (Cabane).
- [[concept-specialist-moat]] -- be the Olympist: world-class niche depth and taste are the moat AI cannot commoditise (Cabane, Moscatiello; spiky mutants, Camhi).
- [[concept-earn-the-right-to-automate]] -- prove the motion manually before scaling it; automating mediocrity just makes more noise (Camhi, Adelstein).
- [[concept-adoption-as-prioritisation]] -- democratise agent-building, let real adoption signal which workflows to productionise (Khanna, Adelstein).
- [[concept-llm-wiki-pattern]] -- the raw / wiki / schema compounding knowledge base an LLM maintains; the structural spine of this vault and the parent of the GTM context-repo frameworks (Karpathy).
