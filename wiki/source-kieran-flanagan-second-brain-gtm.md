# Source: Kieran Flanagan -- I built an AI Second Brain (10x better GTM leader)

> [[expert-kieran-flanagan]]'s account of building an Obsidian + Claude Code "Second Brain" before taking over a 400+ person org. The GTM-leadership instance of [[concept-llm-wiki-pattern]]. Raw: `raw/I built an AI Second Brain...md`.

## Summary

Flanagan built the system over three months and calls it the single most impactful thing he has done with AI, changing the quality and speed of his decisions. The architecture is the LLM-wiki pattern aimed at executive GTM work:

- **Two halves that need each other.** An **Obsidian vault** (plain markdown, organised into folders that each have a job, browsable as a connected graph) holds the structured knowledge; **[[tool-claude-code]]** is the intelligence that reads, writes, and reasons across it in the terminal. "A vault without AI is a wiki that decays because no one has time to maintain it. AI without a vault starts from zero every session and forgets everything the moment you close the tab."
- **CLAUDE.md is the constitution.** It holds identity, voice, non-negotiables, and conventions, and is auto-loaded every session alongside the project index and recent daily logs, so the agent has full strategic context before a word is typed. Co-evolved with use; it gets sharper over time.
- **Persistence is the difference** from dropping a question into a stock chat instance: the system carries strategic context session to session, so decisions compound rather than restart.
- **Why it mattered.** Taking over a large org normally means months of meetings, decks, and chasing down what worked, who knows what. Having the Second Brain built beforehand changed how he worked from day one.

## Key takeaways

- A GTM leader's "second brain" = Obsidian vault (knowledge) + Claude Code (reasoning), neither useful alone.
- CLAUDE.md as an auto-loaded operating constitution is what makes sessions continuous.
- Build it before you need it; the compounding context is the moat.
- Same raw/wiki/schema shape as [[concept-llm-wiki-pattern]] and the GTM context-repo frameworks.
