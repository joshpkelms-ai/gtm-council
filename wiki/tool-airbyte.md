# Tool: Airbyte

> Data-integration platform building a "Context Store" and agents for GTM: pre-assemble and unify your data behind one MCP endpoint so agents read one clean view. The corpus's reference implementation of [[concept-context-assembly]].

## What it is

A data-movement platform (50+ connectors: Gong, Salesforce, Zendesk, LinkedIn, Jira, HubSpot, etc.) extending into agent territory. The Context Store replicates and indexes your business into a search-optimised source of truth, queryable by ChatGPT, Claude, Gemini, and Llama, and fronted by a single MCP connection that follows the agent across tools. Airbyte Agents (Marketing, Sales, Support, Product Marketing) read that store and write back to close the loop in the CRM and other GTM tools.

## Position in the corpus

[[expert-matteo-tittarelli]] (a brand partner) uses it to make the upstream-context argument: assemble and unify context first, then let the agent read it, rather than stitching conflicting sources at query time. The work is attributed in-post to "Mario" -- [[expert-mario-moscatiello]], Airbyte's VP of Marketing, who details the warm-outbound motion built on this foundation in [[source-mario-moscatiello-foundations-before-automation]].
