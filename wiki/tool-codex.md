# Tool: Codex

> OpenAI's agentic coding tool. Appears in the corpus alongside [[tool-claude-code]] as the other agentic CLI GTM engineers build on, often paired in the same plugin.

## What it is

An agentic coding agent (OpenAI). In GTM-engineering contexts it is used interchangeably with or alongside [[tool-claude-code]] for shipping campaign analysis, outbound copy, CRM cleanup, ICP scoring, customer research, and sales reports.

## Position in the corpus

- **Paired with Claude Code in plugins.** [[expert-andy-toizer]]'s GTM Brain Builder ships as a "Claude Code + Codex plugin". Codex looked across company context, analytics, CRM, and sources to explain what each customer proved about Freckle. See [[framework-gtm-brain]] and [[source-andy-toizer-gtm-brain]].
- **Eric Nowoslawski's primary harness.** [[expert-eric-nowoslawski]] recommends starting with Codex's desktop app (controls desktop and browsers) and runs his agents-as-employees method on it: /goal mode for many tasks from one terminal ([[play-agentic-goal-run]]), task sub-agents for near-free list cleaning ([[play-cheap-list-processing]]), and the $200 plan's hard-to-exhaust weekly usage. See [[framework-ai-employee-loop]].

## /goal mode

A mode where Codex works toward a defined end state across many steps. The remaining human skill is specifying done precisely and verifying it; commenters recommend step-wise checkpoints with explicit QA criteria to bound cost.
