# Tool: Gong

> Conversation-intelligence platform: records, transcribes, and analyses sales calls. Recurs across this corpus as the canonical source of what customers actually say, and increasingly as a data source agents read from.

## Why it matters here

Gong shows up in three roles across the vault:

- **Customer-voice digest.** [[expert-mario-moscatiello]]'s one starting habit is a Gong digest of what customers say -- stop doom-scrolling, listen to the market (see [[source-mario-moscatiello-foundations-before-automation]]).
- **A foundation tool to get right.** Netic names Gong alongside Salesforce as part of "getting the foundations right" before building on top with Claude Code and Clay ([[source-brendan-short-rippling-netic-earn-to-automate]]).
- **A gated agent data source.** Vanta built custom MCPs on top of Gong (and Snowflake) to gate what reps can access and to clean out garbage before agents read it -- "particularly important with Gong data" ([[source-noah-adelstein-vanta-dust-agent-builders]]). Feeds [[concept-silent-failures]] and [[concept-context-assembly]].
- **A coaching input.** Koen Stam's Sales Coaching System connects to Gong (or Leexi) to run call transcripts through a framework-grounded coaching agent ([[source-koen-stam-processes-first-gtmcraft]]).
