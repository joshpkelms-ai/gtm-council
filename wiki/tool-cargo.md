# Tool: Cargo

> A "workbench for GTM engineers": a no-code/low-code platform for spinning up MCP servers, vector search, and GTM automations, with a community attached.

## What it is

Cargo positions itself as a place for GTM engineers to test, play, and then scale ideas. In this corpus it appears as the host of a workshop on building a GTM-specific [[tool-mcp]] server without writing TypeScript: prototype a tool, see if it is useful, then build workflows on top. It also runs a GTM engineer community (Slack, events, themed content months).

## Position in the corpus

- **No-code MCP servers.** Cargo's pitch is that GTM engineers should not spend time on TypeScript and hosting to get an MCP server running; spin one up, prototype, ship, and custom-code later only if you need full control. See [[source-cargo-mcp-gtm-workshop]].
- **Community as distribution.** Mirrors the community-led motion elsewhere in the corpus (GTM Engineer School, the various newsletters): a tool plus a gathering place for the practitioners using it.
