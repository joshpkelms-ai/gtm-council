# Rafid Imran

> Runs growth at Yuma AI (a customer experience platform for ecommerce brands). Migrated Yuma's entire marketing site off Webflow onto a code-based stack managed almost entirely through [[tool-claude-code]], shipping pages in hours instead of days as a one-person web team. Published on [[expert-noah-adelstein]]'s the gtm engineer.

## Who he is

A solo growth operator doing the work of five: web dev, content, ads, product launches, events, competitor intelligence, marketing automation. His unlock was treating the marketing site as a Claude-Code-readable repo rather than a no-code CMS.

## Core positions

- **Code-first marketing site beats no-code.** Webflow capped the speed of marketing experiments; a Next.js/Vercel/TypeScript stack lets an agent build any custom page, animation, or localisation on demand. See [[play-code-first-marketing-site]].
- **Claude skills are the most useful infrastructure.** A skill is a written runbook for a recurring web job (add a case study, spin up a comparison page, run the SEO preflight). What was a 15-step manual checklist becomes one prompt, and every workflow becomes institutional knowledge. Ties to [[concept-skill-namespacing]] and [[framework-strategy-as-repo]].
- **Build the stack so an agent can read it.** "Every tech in the stack is something Claude Code can understand" -- schemas, file conventions, validators, and skills readable to an agent the same way they are to a human. A concrete instance of [[concept-agent-readiness]].
- **AEO/GEO is baked in, not bolted on.** llms.txt and .md endpoints, JSON-LD structured data, server-rendered HTML so AI crawlers can read and cite the pages. See [[concept-aeo]].

## Results (self-reported)

First 30 days post-migration: users +13%, page views +27%, bounce rate -21%. Recurring cost dropped from ~$5,000/year (Webflow + Weglot) to ~$500/year (Vercel Pro).
