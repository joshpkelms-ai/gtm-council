# Tool: Exa

> A semantic / embeddings-based search API used for agentic research inside enrichment workflows. Praised in the corpus for lead gen and finding lookalikes across the open web.

## What it is

A search API built on embeddings and semantic similarity rather than keyword matching. Used by agents to run research tasks against the open web.

## Position in the corpus

- **Inside Deepline.** [[tool-deepline]] uses Exa to perform agentic research tasks and write the findings to the enrichment table. See [[source-patrick-spychalski-waterfall-claude-code-deepline]].
- **Why practitioners rate it.** Comments on that post call out semantic similarity search as overhauling keyword-matching workflows, and as strong for lead gen and finding lookalikes across a wide array of online sources.
